# Content Rules

## Voice

Friendly, short, direct, encouraging.

## Beginner language

Use Vietnamese explanations in early lessons by default.

## Feedback examples

Good:
- “Chính xác!”
- “Gần đúng rồi. `你好` đọc là `nǐ hǎo`.”
- “Thử nghe lại một lần nữa.”

Avoid:
- “Sai!”
- long grammar lectures inside feedback.

## Lesson text

One concept per explanation.
Advanced explanation can live behind “Tìm hiểu thêm”.
