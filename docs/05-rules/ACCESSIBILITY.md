# Accessibility

## Required baseline

- keyboard navigation;
- visible focus;
- semantic headings;
- labels for form controls;
- ARIA only when native semantics are insufficient;
- sufficient text contrast;
- meaningful alt text;
- reduced motion support;
- no information encoded by color alone.

## Learning-specific

Audio activity must also provide:
- replay;
- text/alternative where learning objective permits.

Correct/incorrect:
- icon + text + color, not color alone.

Chinese characters:
- large enough to inspect comfortably.
