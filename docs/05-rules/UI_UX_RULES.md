# UI / UX Rules

## Mandatory

- One primary CTA per major state.
- Strong visible focus states.
- Disabled state must be obvious.
- Interactive card must look interactive.
- Empty states tell user what to do next.
- Error messages explain recovery.
- Loading state must not cause violent layout shift.

## Avoid admin-dashboard look

This is a learning product, not ERP software.

Avoid:
- tiny dense tables;
- excessive borders;
- sidebar with dozens of items;
- gray corporate dashboard everywhere.

## Cards

Cards should exist only when grouping matters.
Do not put every paragraph in a card.

## Copy

Prefer:
- “Tiếp tục học”
- “Bắt đầu bài đầu tiên”
- “Thử lại”

Avoid:
- “Execute”
- “Module”
- “Curriculum node”
for beginner-facing UI.
