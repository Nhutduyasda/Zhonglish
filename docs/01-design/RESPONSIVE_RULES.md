# Responsive Rules

## Approach

Mobile-first.

Reference breakpoints may follow Tailwind defaults unless product needs otherwise.

## Mobile

- single column;
- 16–20px outer padding;
- touch target >= 44px;
- sticky bottom CTA allowed in lesson;
- no hover-dependent information;
- bottom navigation can replace desktop sidebar.

## Tablet

- preserve content hierarchy;
- avoid simply shrinking desktop layout.

## Desktop

- max readable content width;
- app can use sidebar;
- lesson content remains centered, not stretched.

## Landing

Hero should recompose vertically on mobile.
Do not keep desktop illustration overlapping text when it harms readability.
