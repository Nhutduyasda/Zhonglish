# Landing Page — Skolla Direction

## Objective

Landing page phải khiến người mới cảm thấy:
“Trang này dễ học, đẹp, nhẹ và mình có thể bắt đầu ngay.”

## Section order

1. Navbar
2. Hero
3. Trust/social proof
4. Why learning feels easier here
5. Language selection
6. Learning experience preview
7. How it works
8. Progress/gamification preview
9. Testimonials
10. Optional pricing
11. FAQ
12. Final CTA
13. Footer

## Hero

Must contain:
- short headline;
- one supporting sentence;
- main CTA;
- secondary CTA only if necessary;
- visual/illustration/product mockup.

Avoid:
- 3+ CTAs;
- long paragraph;
- technical terms.

## Skolla fidelity checklist

- strong whitespace;
- large typography;
- soft rounded sections/cards;
- playful but controlled graphics;
- clear conversion flow;
- responsive composition;
- content width kept readable.

## Landing vs App

Do not copy landing navigation into learning dashboard.
The app needs its own compact navigation.
