# Design Direction

## Visual north star

Public website phải tạo cảm giác gần với **Skolla** ở:
- clean educational landing page;
- generous spacing;
- strong headline;
- modern rounded cards;
- editorial section rhythm;
- friendly illustrations/photos;
- clear CTAs;
- conversion-oriented sequence.

Learning area chuyển sang app-like UI lấy cảm hứng từ:
- Uizard Language Learning;
- Duolingo;
- HelloChinese.

## Important

“Giống Skolla” nghĩa là giữ:
- visual density;
- composition logic;
- spacing character;
- rounded geometry;
- hierarchy;
- approachable educational feel.

Không có nghĩa là copy:
- logo;
- illustration;
- exact text;
- source;
- image;
- proprietary asset.

## Brand direction

Working brand can be changed later.

Tone:
- modern;
- youthful but not childish;
- friendly;
- international;
- bright;
- confidence-building.

## Layout philosophy

Public pages:
`storytelling sections`

App pages:
`task-focused screens`

Lesson pages:
`single-task focus`
