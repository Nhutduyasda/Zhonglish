# Motion Guidelines

## Technology

Framer Motion is preferred.

## Purpose

Motion must:
- explain state change;
- reward success;
- guide attention;
- make page feel alive.

Motion must not:
- delay primary action;
- continuously distract;
- move large content unnecessarily;
- ignore reduced-motion preference.

## Timing

Typical UI:
- 150–250ms.

Page/section:
- 300–500ms.

Reward:
- up to ~700ms if non-blocking.

## Good examples

- card hover lift;
- button press scale;
- progress bar animate to new value;
- answer correct check;
- XP count-up;
- streak flame pulse;
- section fade/translate on first entrance.

## Avoid

- parallax everywhere;
- long splash screens;
- autoplay carousel;
- bouncing CTA forever.
