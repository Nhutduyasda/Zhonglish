# Chinese Beginner Path

## Stage 0 — First contact

- 你好
- 谢谢
- 再见
- 是 / 不是
- basic sounds;
- pinyin introduction.

## Stage 1 — Me

- 我
- 你
- 他 / 她
- name;
- nationality;
- numbers.

## Stage 2 — Daily life

- food;
- family;
- time;
- common verbs;
- question patterns.

## Stage 3 — Practical communication

- shopping;
- restaurant;
- travel;
- directions;
- workplace basics.

## Character presentation

When a new word is introduced, UI may show:

```text
你好
nǐ hǎo
Xin chào
[🔊]
```

Do not overload beginners with stroke theory before they have context.
