# Learning Model

## Beginner-first lesson design

Each lesson:
- 3–5 minutes target;
- one small objective;
- immediate feedback;
- visible progress;
- review mistakes before exit when appropriate.

## Exercise primitives

- choose image;
- choose meaning;
- arrange words;
- listen and choose;
- listen and type;
- speak/repeat;
- fill blank;
- match pairs;
- identify Chinese character;
- identify pinyin;
- simple writing trace later.

## Difficulty

Introduce:
1. recognition;
2. guided recall;
3. free recall;
4. listening/speaking;
5. mixed review.

Never introduce many new concepts simultaneously.
