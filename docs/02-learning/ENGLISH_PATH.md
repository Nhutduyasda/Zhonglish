# English Beginner Path

## Stage 0 — Survival

- Hello / Goodbye.
- My name is…
- Yes / No.
- Thank you.
- Numbers.
- Basic objects.

## Stage 1 — Me

- introductions;
- country;
- job;
- family;
- age;
- simple `be`.

## Stage 2 — Daily life

- food;
- time;
- routines;
- places;
- simple present.

## Stage 3 — Practical communication

- shopping;
- directions;
- ordering food;
- travel;
- basic workplace phrases.

## UX principle

Do not title first screen “A1 Grammar”.
Use practical titles such as:
- Say hello
- Introduce yourself
- Order a drink
