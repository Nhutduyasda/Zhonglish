# User Flows

## New visitor

```text
Landing
→ Start learning
→ Choose English / Chinese
→ Choose goal
→ Choose daily time
→ Create account or continue guest strategy
→ First lesson
→ Result
→ Dashboard
```

## Returning learner

```text
Dashboard
→ Continue learning
→ Lesson
→ Result
→ Next lesson / Review
```

## Review mistakes

```text
Dashboard
→ Review
→ Due exercise mistakes (maximum 5 by default, 10 supported)
→ Short review session
→ Server-verified feedback after every answer
→ Result
→ Dashboard
```

Each submitted review answer is saved immediately. Exiting mid-session keeps answered items scheduled and leaves unanswered items due. An empty queue shows a friendly success state instead of a 404.

## Change language

```text
Profile / Language switcher
→ Select course
→ Dashboard updates context
```
