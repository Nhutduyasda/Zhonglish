# User Flows

## New visitor

```text
Landing
→ Start learning
→ Choose English / Chinese
→ Choose goal
→ Choose daily time
→ Create account or continue guest strategy
→ First lesson
→ Result
→ Dashboard
```

## Returning learner

```text
Dashboard
→ Continue learning
→ Lesson
→ Result
→ Next lesson / Review
```

## Review mistakes

```text
Dashboard
→ Review
→ Weak words
→ Short review session
→ Result
```

## Change language

```text
Profile / Language switcher
→ Select course
→ Dashboard updates context
```
