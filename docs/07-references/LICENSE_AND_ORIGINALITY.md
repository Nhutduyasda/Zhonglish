# License and Originality

## Skolla

The Framer Marketplace listing identifies Skolla with a **Limited** license.

Therefore:
- do not copy or redistribute its source as part of this project unless the applicable license explicitly permits the intended use;
- do not extract and republish its proprietary asset bundle;
- do not present its branding as ours.

## General originality rule

Allowed direction:
- similar spacing philosophy;
- similar hierarchy;
- similar section categories;
- common UI patterns;
- comparable level of polish.

Create independently:
- code;
- copy;
- logo;
- brand;
- illustrations;
- icons where not open-licensed;
- lesson content.

## Public repo

Before open-sourcing:
- verify image licenses;
- verify font licenses;
- include required attributions;
- remove copied demo assets;
- ensure secrets are absent.
